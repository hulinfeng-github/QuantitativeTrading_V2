## ⚡ 核心子策略与量化模型详解

### 1. ⚡ 游资龙虎打板量化与自动台账自进化引擎 (`LimitUpEngine 2.0`)
吸收 GitHub 顶级 A 股游资实战战法与量化研报：专注沪深主板涨停板型结构，建立分时封板质量评分体系，并在每日收盘复盘时**全自动创建并维护实战流水账本**。

#### A. 5 大主板涨停板型分类识别
1. **首板突破**：底部平台蓄势或均线粘合后的第一根大阳放量涨停，起爆安全边际极高，无高位监管风险；
2. **1进2接力**：分歧转一致换手板，主力增量资金共识加速形成；
3. **2进3接力**：空间梯队标杆，博弈主升浪龙头高溢价；
4. **高位连板龙头**：4板及以上穿越周期的市场情绪总龙头；
5. **弱转强反包板**：前一日冲高回落长上影或假阴线洗盘，次日早盘快速反包封死涨停。

#### B. 分时封板硬度打分系统 (`hardness_score`，0~100 分)
- **封板时间因子**：早盘 09:30~10:00 秒板 (90~98分) > 盘中换手板 (75~85分) > 尾盘偷袭烂板 (50~65分)；
- **封成比 (封单金额 / 全天成交额)**：封成比 $\ge 15\%$ 视为坚挺，$\le 3\%$ 视为弱板；
- **炸板回封次数**：一封到底 > 1次分歧回封 > 多次开板烂板；
- **量比与均线共振**：显著放量（量比 $\ge 1.5$ 倍）或缩量一字板，均线多头排列。

#### C. 实战流水账本自动维护与导出
- **存储路径**：
  - JSON 核心数据：`storage/limit_up_trades.json`
  - 电子表格：`storage/limit_up_ledger.csv`（**采用 `utf-8-sig` (带 UTF-8 BOM) 编码，Windows 下双击使用 Microsoft Excel 或 WPS 秒开 100% 杜绝乱码！**）
- **复盘自动 T+1 真实行情结算**：
  每日 15:10 收盘全景复盘时，系统自动拉取前一交易日打板标的的 T+1 真实开盘价、最高价、收盘价，自动核算并回填：
  - **次日竞价高开溢价率**（次日开盘盈亏 %）
  - **次日盘中最高冲高收益**（次日最高价冲高盈亏 %）
  - **次日收盘净收益**（次日收盘盈亏 %）
  - **连板晋级状态**（是否成功晋级二连板/三连板）
  - **模型全周期胜率、盈亏比与大面率统计**（跌幅 $\ge 4\%$ 判定为大面）

#### D. 📖 新手小白打板实战保姆级必读操作指南
针对新手不知道“应该在什么点？具体怎么操作？”的痛点，系统提供标准化操盘执行手册：

```
                ┌─── 1. 【扫板买点】(主选·高确定性): 涨幅 +9.5%~+9.8% 卖一将被扫空瞬间 ─── 选限价买入，直接填涨停价
打板买入两途径 ─┤
                └─── 2. 【排板买点】(次选·封死排队): 涨停封死后挂单排队 ──────────────────────── 随时盯盘，封单衰减立即【撤单】
```

1. **应该在什么点买？具体怎么操作？**
   - **扫板点 (首选推荐)**：股价分时脉冲至 **+9.5% ~ +9.8%**（例如涨停价为 16.89 元，当股价跳至 16.80~16.85 元）、卖一涨停价剩余挂单即将被大资金扫光一瞬间，立即在交易软件中选择**【限价买入】**，价格直接输入今日**涨停价（16.89元）**，点击买入；
   - **排板点 (封死排队)**：股票封死后以涨停价挂单排队。**【防守撤单关键】**若盘中封单大幅衰减至 5000 手以下或万手砸盘即将开板，**必须立刻点击【撤单】**，严禁在开板下杀过程中无脑接飞刀！
   - **仓位管理**：建议单笔控制在总资金 **10% ~ 15%**，小白严禁满仓一把梭！
2. **次日 (T+1) 应该在什么点卖？具体怎么操作？(三大剧本实操)**
   - **【剧本 A · 正常早盘冲高止盈 (最常见核心利润来源)】**：次日早盘 **09:30 ~ 09:45** 惯性脉冲上攻触及 **+3.0% ~ +5.0%** 目标区间或分时跌破黄线滞涨时，**不要贪心，立即以市价全部卖出止盈**，锁定隔日利润！
   - **【剧本 B · 超预期大高开/秒板连板 (享受主升加速)】**：若次日 09:25 集合竞价大幅高开 **+4.0% 以上** 或开盘 3 分钟内直接秒封涨停板，**持股不动**，享受二连板/三连板龙头溢价；若封板后开板且 1 分钟内未能迅速回封，立即市价全额卖出！
   - **【剧本 C · 不及预期/大幅低开破位 (绝不扛单严格止损)】**：若次日大幅低开低于 -2.0%，或盘中跌破防守止损线 **-3.0%**，**绝不心存侥幸！绝不补仓！立即以市价挂单止损卖出**，防止深套吃大面！

### 2. 📊 深度经营状况财报分析与六维排雷引擎 (`FinancialEngine`)
收盘选股后深度穿透上市公司财报，确保入选标的不仅技术面走强，同时基本面扎实稳健：
- **杜邦 3 因子核心分解矩阵**：
  $$\text{ROE} = \text{销售净利率 (Net Margin)} \times \text{总资产周转率 (Asset Turnover)} \times \text{权益乘数 (Equity Multiplier)}$$
  自动归因企业盈利模式（高净利护城河型 / 高周转运营型 / 杠杆驱动型）；
- **皮奥特罗斯基 Piotroski 9 维价值评分 (F-Score)**：
  从盈利能力、运营效率与财务杠杆 9 个维度严苛打分 (0~9分)；
- **A 股专属六维财务避雷排雷雷达**：
  - 商誉减值隐患：商誉/净资产 $\ge 20\%$ 预警；
  - 应收账款坏账风险：应收账款/营收 $\ge 35\%$ 警惕；
  - 存货积压跌价：存货/总资产 $\ge 40\%$ 警惕滞销跌价；
  - 现金流与净利润匹配度：经营净现金流 / 归母净利润 $< 0.3$ 严厉惩罚“纸面富贵”；
  - 重资产高负债断裂危机：资产负债率 $\ge 78\%$ 严控流动性危机；
- **企业画像定调与一票否决机制**：
  自动评定 `💎【现金奶牛·核心白马资产】`、`🚀【高景气·高成长主升白马】`、`🏰【高护城河·品牌溢价龙头】` 等画像。触碰财务雷区标的在多因子选股中实行**一票否决式降权过滤**。

  - **09:28 集合竞价作战计划**：竞价定调，明确开盘点位与操盘指导；
  - **09:30~09:45 冲高止盈 (`TAIL_PROFIT_EXIT`)**：触达 +2.5% 目标价果断市价全额卖出；
  - **破位止损 (`TAIL_STOP_EXIT`)**：跌破 -1.8% 防守线坚决挂单止损避险；
  - **动能衰竭时限离场 (`TAIL_TIMED_EXIT`)**：09:45 动能衰竭分批离场；
  - **尾盘清仓 (`TAIL_EOD_EXIT`)**：严格执行一夜持股纪律，尾盘必须全额清仓，绝不二次留仓过夜。

### 4. 🎯 A股 T+1 日内做T动态布林通道与强制平仓风控 (`T0SmartEngine`)
针对持仓底仓进行日内 T+1 差价对冲套利：
- **倒T (高抛低吸)**：开盘脉冲向上突破动态布林上轨时发出高抛卖出信号，回踩均线低吸买回；
- **正T (低吸高抛)**：早盘下探回踩支撑发出低吸买入信号，冲高反抽高抛平仓；
- **14:48 尾盘强制平仓纪律**：
  - **正T强平 (`EOD_FORCE_CLOSE_T`)**：若买入加仓股份盘中未达目标，必须在 14:55 集合竞价前市价卖出老底仓，**严禁做T演变为被动加仓过夜套牢**；
  - **倒T对冲抉择 (`EOD_HEDGE_ALERT_T`)**：根据个股强弱自主抉择回补底仓或顺势保留现金。

### 5. 💎 多因子共振波段模型 (Alpha + RSRS 2.0 + CYQ 2.0)
- **偏度修正 RSRS 2.0 算法 (Skewness-Penalized RSRS)**：
  对过去 18 天高低价 OLS 回归斜率 $\beta$ 进行滑动 600 天 $Z\text{-score}$ 标准化，并引入金工残差偏度修正（Skewness Penalty），有效过滤诱多尖刺与日内假脉冲；

- **现代化组合风控**：
  基于半凯利公式 (Half-Kelly) 与波动率平价 (Volatility Parity) 动态配置建议个股仓位 (10%~25%)。

## ❓ 常见问题与解答 (FAQ)

### Q1: 为什么有时候收盘选股雷达没有推送股票？
- **A**: 策略严格设定了多重安全门槛：
  1. **大盘情绪熔断**：当大盘情绪温度计 $< 15$ 分（处于“极度冰点”或“系统性杀跌”通道）时，策略会自动收缩甚至归零风险敞口，杜绝弱市逆势接盘；
  2. **多因子共振与财报排雷**：要求修正 RSRS 突破买点、主力筹码集中度 $\le 12\%$、且杜邦净利率坚挺、无商誉高危或坏账隐患。若当日全市场无标的满足共振标准，系统会发出“今日保持空仓防守”提醒，绝不滥发低质量信号。

### Q2: 财报与经营状况数据来自哪里？财报更新后会自动同步吗？
- **A**: 财报数据直接对接东方财富与新浪财经官方披露接口，实时解析最新资产负债表与利润表。系统内置增量更新机制（本地持久化于 `storage/financial_cache.json`），上市公司发布一季报、中报、三季报或年报披露后，系统会自动检测更新时间戳并刷新指标，杜绝滞后。对 ETF 基金已自动内置免疫过滤规则。

### Q3: 导出的打板表格在 Windows 上用 Excel 打开为什么不会乱码？
- **A**: 系统在导出 `storage/limit_up_ledger.csv` 时采用了工业标准的 **`utf-8-sig` (带 UTF-8 BOM)** 编码。Microsoft Excel 与 WPS 会自动识别 BOM 签名，无需在导入向导中繁琐设置编码，双击即可直接秒开。

### Q4: 如何配置钉钉和微信机器人推送？
- **A**: 在 Web 控制台右上角切换到 **`⚙️ 策略与推送配置`** 标签：
  - **钉钉**：填入群机器人的 WebHook 地址与加签密钥（Secret），点击保存并测试；
  - **微信**：支持免费的 PushPlus（微信公众号弹窗，推荐，免装 App）、Server酱或企业微信群机器人，填入 Token 保存即可。
